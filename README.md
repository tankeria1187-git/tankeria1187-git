## Проекты

### 🎮 [Крестики-нолики на Tkinter](https://github.com/tankeria1187-git/tic-tac-toe-tkinter)
GUI-игра с разделением логики и интерфейса. Игровая логика не зависит от Tkinter и покрыта тестами (pytest): все 8 выигрышных линий, ничья, невалидные ходы, сброс. Состояние игры — `Enum`, а не bool-флаги.

`Python` · `Tkinter` · `pytest` · `Enum` · `dataclass`

### 💱 [Курсы валют ЦБ РФ](https://github.com/tankeria1187-git/cbr-rates-tkinter)
Мини-приложение на Tkinter: запрос к официальному API ЦБ РФ, парсинг XML, деление на номинал (для юаня — на 10, для воны — на 1000). Кэш на один запрос, обработка сетевых ошибок, выбор валюты из списка.

`Python` · `Tkinter` · `requests` · `XML` · `API`

### 🌤️ [Weather CLI](https://github.com/tankeria1187-git/weather-cli)
Консольная утилита для получения погоды через WeatherAPI. Меню, запрос к API, обработка ошибок (401, 400, таймаут), проверка города, сохранение истории в JSON, статистика. Секреты — в `.env` (с `.env.example` в репозитории). Запускается в Docker.

`Python` · `requests` · `python-dotenv` · `JSON` · `Docker`

### ☕ [Coffee Shop](https://github.com/tankeria1187-git/coffee-shop)
Одностраничный лендинг магазина кофе: каталог из 6 товаров (адаптивная сетка `auto-fill` + `minmax`), поиск по названию, корзина с toast-уведомлением при добавлении, форма обратной связи с валидацией без перезагрузки страницы. Без бэкенда — чистый HTML, CSS, JavaScript. Живая версия: https://tankeria1187-git.github.io/coffee-shop

`HTML` · `CSS` · `JavaScript`

### 💰 [Finance Tracker](https://github.com/tankeria1187-git/finance-tracker)
Консольная утилита для личного учёта доходов и расходов. Суммы в целых копейках — без float‑ошибок; итоги всегда считаются из деталей, отдельного хранилища нет. Атомарное сохранение, защита от битого JSON (копия `.corrupt-<время>`), нормализация старого формата, сброс с подтверждением. Зависимостей нет — только стандартная библиотека. 

`Python` · `JSON` · `pytest`

## Что я умею

- **GUI на Tkinter** — окна, кнопки, поля ввода, списки, обработка событий. Разделяю логику и интерфейс: логика тестируется без запуска окна.
- **Работа с API** — GET-запросы, `timeout`, обработка HTTP-кодов (`401`, `400`), парсинг JSON и XML, кэширование.
- **Обработка ошибок** — понятные сообщения вместо трейсбеков. Конкретные исключения (`Timeout`, `ParseError`), а не `except Exception`.
- **ООП** — классы, инкапсуляция, `@property`, `Enum`, `dataclass`.
- **Тесты** — pytest: параметризация, тесты на граничные случаи, изоляция от сети.
- **Консольные утилиты** — меню, ввод с валидацией, атомарная запись в JSON, защита от битых данных, работа без внешних зависимостей.
- **Docker** — `Dockerfile`, `docker build`, `docker run`, передача секретов через `--env-file`.
- **Git** — осмысленная история коммитов, `.gitignore`, безопасная работа с секретами.
