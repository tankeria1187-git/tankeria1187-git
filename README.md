# Привет!

Это моё портфолио на Python. Сейчас выкладываю проекты, скоро добавлю описания, скриншоты и инструкции по запуску.

## Что уже есть в работе

- **«Крестики‑нолики» на Tkinter** — тренирую чёткое разделение игровой логики и UI: интерфейс реагирует на события, но не хранит состояние игры.
- **Набор классов с валидацией и инкапсуляцией** — прокачиваю ООП и покрытие тестами (pytest). Примеры: валидация возраста в `User`, управление температурой в `Thermostat`.
- **Приложение Weather CLI** — консольная утилита: меню, запрос к API, обработка ошибок и таймаутов, сохранение истории в JSON. Отдельно продумана безопасность: секреты вынесены в `.env`, для других есть `.env.example`, в истории — понятные коммиты.
- **Примеры работы с БД** — учусь проектировать простые схемы, писать миграции и делать базовые запросы.

## Стек

- Python 3
- Tkinter
- pytest
- SQL (базовый уровень)
- Git / GitHub — аккуратная история коммитов, понятные сообщения (`feat`, `docs`, `test`), `.gitignore`, безопасная работа с секретами.
